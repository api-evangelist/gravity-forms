Gravity Forms 2.10.3 brings security enhancements and bug fixes, removing a console log that displayed feeds on the frontend and eliminating dynamic population for the File Upload field. This core release continues to position Gravity Forms as the platform that transforms WordPress forms into operational systems supporting payments, registrations, approvals, and automated workflows.
