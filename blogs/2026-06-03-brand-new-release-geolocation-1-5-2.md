The Gravity Forms Geolocation Add-On 1.5.2 now enables the new Google Places API by default and resolves an issue where multiple address inputs were populated incorrectly when Geolocation Suggestions was enabled across multiple forms on the same page. This add-on leverages Google Places to provide address autocomplete and capture location data for form submissions.
